# ngx-prime MCP server

This package provides Model Context Protocol (MCP) access to ngx-prime component documentation, APIs, theming information, and examples.

It is maintained independently by Web Art Work and contributors as part of ngx-prime, an MIT-licensed continuation of the ngx-prime v21.1.9 codebase. The current package identifier is retained for compatibility and will be reviewed as part of a separate npm/API migration.

For project information and attribution, see the [ngx-prime repository](https://github.com/WebArtWork/ngx-prime).
